Todoist

将 Jellyfin 剧集同步到每个用户的 Todoist 项目。新增剧集创建任务，观看完成后自动完成任务。

OAuth 应用配置

在 Todoist 开发者控制台创建应用，回调地址填写 Jellyfin 公网地址加 /Todoist/Callback（包含 Jellyfin Base URL）。

仅服务器使用，不会发送给其他用户。

我的 Todoist

首次保存会同步所有可访问的未观看剧集，建议使用独立项目。切换项目会保留原项目任务。

解除关联会清除本地授权和映射，保留 Todoist 任务。需彻底撤销授权时，在 Todoist 集成设置中移除本应用。
